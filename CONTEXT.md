# Berth

Berth keeps the macOS Dock on the display chosen as its persistent berth.

## Language

**Pinned Display**:
The display Berth remembers as the Dock's berth, including while that display is temporarily disconnected.
_Avoid_: Selected Display, Chosen Display, Target Display

**Dock Control**:
The user-facing state in which Berth keeps the Dock on the Pinned Display.
_Avoid in user-facing text_: Interception, guarding
