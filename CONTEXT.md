# Berth

Berth keeps the macOS Dock on the display chosen as its persistent berth.

## Language

**Pinned Display**:
The display Berth remembers as the Dock's berth, including while that display is temporarily disconnected.
_Avoid_: Selected Display, Chosen Display, Target Display

**Dock Control**:
The user-facing state in which Berth keeps the Dock on the Pinned Display.
_Avoid in user-facing text_: Interception, guarding

**App Language**:
The language selection macOS manages for Berth's own user-facing text, either by following the system language preferences or through a per-app override in Language & Region.
_Avoid_: Locale, Interface Language

**Effective Language**:
The App Language used by the current Berth process, determined by macOS when Berth launches.
_Avoid_: Current Locale, Active Locale
