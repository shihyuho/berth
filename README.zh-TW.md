## 使用 Homebrew 安裝

```sh
brew tap shihyuho/tap
brew install --cask shihyuho/tap/berth
```

需要 Apple Silicon 與 macOS 13 以上版本。Berth 需要「輔助使用」權限才能固定 Dock。
