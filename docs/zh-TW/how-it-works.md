# 運作原理

[English](../how-it-works.md) · 繁體中文

當 macOS 對每個顯示器使用獨立空間時，把游標持續推向 Dock 邊緣，便能將 Dock 召喚到另一個螢幕。Berth 會在非指定螢幕阻止這個手勢完成。

Berth 透過 `CGEventTap` 接收全域滑鼠移動與拖曳事件。在其他螢幕的外側 Dock 邊緣，它會讓游標與觸發區保持至少 2 px 的距離。螢幕之間的共用邊界會保持暢通，游標仍可正常穿越螢幕。

如果 Dock 仍移動到其他螢幕，Berth 會檢查位置，並在指定螢幕重現正常的召喚手勢。它支援位於下方、左側或右側的 Dock。

## 螢幕變更

Berth 會保存所選螢幕的識別資訊。如果該螢幕消失，Berth 會安全地停止攔截。重新連接該螢幕，或從選單選擇另一個螢幕即可。

## 隱私與權限

Berth 需要「輔助使用」權限，因為它會讀取滑鼠移動，並產生用來召回 Dock 的滑鼠事件。Berth 不會監看鍵盤、保存輸入內容或透過網路傳送資料。

撤銷「輔助使用」權限後，Berth 會自動停止攔截。
